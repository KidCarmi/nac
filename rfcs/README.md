# RFCs

RFCs (Requests for Comments) are design proposals for substantial changes —
new subsystems, breaking API changes, or cross-cutting concerns — that warrant
discussion *before* implementation. Lightweight decisions are recorded directly
as [ADRs](../adr/README.md); RFCs are for proposals that need review first and
typically result in one or more ADRs once accepted.

## Process

1. Copy [`0000-template.md`](0000-template.md) to `NNNN-short-title.md`.
2. Open a pull request; iterate with reviewers.
3. On acceptance, implement and record resulting decisions as ADRs.
