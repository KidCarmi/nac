# Reproduce the rc10 DHCP server comparison

This run changes only the two disposable DHCP service guests in the isolated `NAC-Pilot-DHCP.unl` topology. Preserve the published BusyBox udhcpd one-hour baseline and the original 120-second configs. Do not copy vendor media, test keys, shared secrets or admin credentials into the evidence package.

1. Verify EVE VM 102 is reachable, `ip_forward=0`, both segment services return HTTP 200 from their own bridges, and only Linux endpoint node 32 uses vEOS Ethernet1. Pin EOS 4.29.2F, NAC commit `b39649f138e126ed6689a53b590855061042e341`, installed nacd SHA-256 `35699eac162cc2a7315efced101bee3ec18ed87ab1cb108f06f9bb1a7b48195e`, FreeRADIUS 3.2.5, Linux `systemd-networkd`, and the endpoint's certificate issuer and serial.
2. On each service guest, record `/etc/nac-udhcpd.conf`, `systemctl is-active nac-udhcpd`, `ss -lunp`, versions and free disk. Do not edit the baseline files. Stage Ubuntu `dnsmasq-base` 2.91-0ubuntu0.22.04.2, package SHA-256 `c999f2c92633d753edcdd67fb039f5866e9413500b2c764993cbb6bb26393309`, using `stage_dnsmasq_via_eve.py`. Its temporary EVE bridge address and host route are removed after each transfer. Stop the transfer-only SSH daemon before the primary test.
3. Before switching the live scope, run `dhcp_rebind_preflight.py` in two separate Linux network namespaces. It sends one broadcast DHCPREQUEST with an old-subnet `ciaddr` and one same-subnet control. Save the pcap and dnsmasq log. The preflight is diagnostic; the actual endpoint packets decide the result.
4. Set `DHCP_COMPARE_ACTION=start` and `DHCP_COMPARE_PORT=32801` or `32802` when invoking `dhcp_compare_console_guest.py` through `eve_guest.py`. Confirm that only dnsmasq listens on UDP/67 on each service guest and its config has `dhcp-authoritative`, 3,600-second lease, the correct subnet, router and DNS options. Verify both HTTP/TCP services again.
5. Start `run_dhcp_candidate.py capture-start --candidate <full-sha> --run <unique-id>` and `probe-start --seconds 4200`. Bounded captures are at most two 8 MiB files per interface, and endpoint JSONL is capped at 8 MiB. Check endpoint free space before starting. Start the existing wired `wpa_supplicant` profile, wait for an EAP-TLS success and a verified one-hour corp DHCP lease. Confirm fresh corp TCP succeeds and quarantine TCP fails.
6. Record the exact DHCPACK time and options 51, 58 and 59. Use the documented NAC Quarantine action shortly after lease acquisition. Do not renew or reconnect the endpoint. Record CoA creation/ACK, Access-Accept VLAN20, switch session, first old-segment denial, and first new-segment success. Observe through the declared 4,200-second probe deadline or recovery. The DHCP capture must show any unicast renewal, broadcast rebind, NAK, Discover and ACK.
7. Once a quarantine lease is stable, start a new bounded probe and capture. Schedule NAC Restore shortly before that lease's advertised T1. Again leave the endpoint untouched through T2, expiry or the declared deadline. Measure old-segment denial and new-segment reachability separately. Any manual `networkctl renew`, `networkctl down/up` or reconnect is a later, explicitly labelled diagnostic.
8. Stop captures, fetch the endpoint probe and all pcaps, parse with `dhcp_packet_timeline.py`, `pcap_timeline.py` and `analyze_linux_lease.py`. Recheck service health, switch state, NAC decision and product version. Restore the original udhcpd service and 120-second scope configuration only after all captures are preserved. Confirm temporary SSH and EVE host routes have been removed.

The maintained server's `dhcp-authoritative` option is documented in the [dnsmasq manual](https://dnsmasq.org/docs/dnsmasq-man.html). That setting is a hypothesis about quicker recovery, not proof. Endpoint DHCP and fresh TCP traces decide whether the server change materially improves access.

Verify the downloaded package before use with `python verify_package.py .` from the package directory. The script checks every byte count and SHA-256 entry in `sha256-manifest.json`, forbids private-key markers and vendor/media extensions, and checks local Markdown links. The published run reached the new segment automatically at T2 in both directions; see [findings](findings.md). The synthetic preflight used a different source IP than the real endpoint's T2 packet and must not be substituted for the real trace.
