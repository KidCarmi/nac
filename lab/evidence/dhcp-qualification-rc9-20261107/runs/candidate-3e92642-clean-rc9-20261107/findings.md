# Exact pilot-rc9 clean-install qualification

**PASS**, 7 November 2026. A separate QEMU/KVM control VM was booted inside EVE VM 102 from a copy-on-write overlay of the authorized Ubuntu 24.04.5 base image. The overlay was expanded to a 12 GB virtual disk (11 GB root filesystem), with 2 vCPUs, 2 GB RAM and user-mode NAT. It had no `/etc/nac`, PostgreSQL or FreeRADIUS installation before this run. Disposable DHCP, root SSH access and host keys were configured only inside this overlay to permit the test. The existing EVE topology, Proxmox bridges, NAC control node and switch were untouched. The overlay is retained at `/root/nac-qualification/clean-rc9-20261107/control-overlay.qcow2` inside EVE; it is **not exported** because it contains test keys and generated secrets.

The exact bundle `nac-pilot-pilot-rc9.tar.gz` passed its packaged SHA-256 check. We followed the pinned commit's `docs/pilot/installation.md`: unpack and run `deployments/pilot/install.sh --test-pki`, without a package proxy because the isolated guest reached the Ubuntu archive directly. The command exited 0.
