# Security Policy

The full security policy, vulnerability reporting process, threat model, and
pre-release security checklist live under [`security/`](security/README.md) and
[`docs/security/`](docs/security/threat-model.md).

**To report a vulnerability:** please disclose privately to the maintainers
rather than opening a public issue. See
[security/README.md](security/README.md#reporting-a-vulnerability) for details.
